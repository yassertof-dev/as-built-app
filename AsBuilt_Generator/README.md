# AsBuilt Drawings Generator

برنامج سطح مكتب (Windows/Linux) يساعد شركات المقاولات على إنتاج مخططات As-Built رباعية التخصصات لـ 70 قطعة أرض أو أكثر.

## 📋 الميزات الأساسية

- ✅ إدخال عدة أرقام قطع في حقل واحد (يدعم الفواصل: `/` `*` `-` `.` مسافة `=` `,` `،` `'`)
- ✅ إنشاء ملف PDF منفصل لكل قطعة
- ✅ أربعة تخصصات: معماري (AR)، مدني (CV)، ميكانيكا (MECH)، كهرباء (ELEC)
- ✅ حفظ آخر رقم تسلسلي لكل تخصص تلقائياً
- ✅ إضافة ودمج مرفقات PDF اختيارية
- ✅ شريط تقدم أفقي وسجل تفصيلي
- ✅ معالجة متوازية بدون تجميد الواجهة (Multithreading)
- ✅ واجهة عربية كاملة (RTL)
- ✅ التحقق من صحة الإدخال

## 🚀 التثبيت

### المتطلبات الأساسية

1. **Python 3.8+**
2. **LibreOffice** أو **Microsoft Word** (لتحويل DOCX إلى PDF)

### تثبيت LibreOffice

#### Windows:
- قم بتحميل وتثبيت LibreOffice من: https://www.libreoffice.org/download/
- تأكد من إضافة LibreOffice إلى PATH النظام

#### Linux (Ubuntu/Debian):
```bash
sudo apt-get update
sudo apt-get install libreoffice-writer
```

#### macOS:
```bash
brew install --cask libreoffice
```

### تثبيت المكتبات Python

```bash
cd AsBuilt_Generator
pip install -r requirements.txt
```

## 🎯 طريقة الاستخدام

### 1. تشغيل البرنامج

```bash
python main.py
```

### 2. إدخال البيانات

1. اختر التخصص من التبويبات العلوية (معماري / مدني / ميكانيكا / كهرباء)
2. أدخل أرقام القطع (مثال: `102030/102031/102032` أو `1-2-3`)
3. اختر التاريخ (افتراضياً تاريخ اليوم)
4. اكتب وصفاً للمخطط (اختياري)
5. اضبط الرقم التسلسلي الابتدائي (يتم اقتراحه تلقائياً)
6. أضف ملفات PDF مرفقة إذا لزم الأمر (اختياري)

### 3. إنشاء الملفات

اضغط على زر **"📄 إنشاء PDF"** وسيبدأ البرنامج في:
- ملء القوالب بالبيانات
- تحويلها إلى PDF
- دمج المرفقات (إن وجدت)
- حفظ الملفات في مجلد OUTPUT/{التخصص}/

### 4. مثال على أسماء الملفات الناتجة

```
OUTPUT/معماري/TOL-ADW-DOC-ASB-AR-001.pdf
OUTPUT/معماري/TOL-ADW-DOC-ASB-AR-002.pdf
OUTPUT/مدني/TOL-ADW-DOC-ASB-CV-001.pdf
OUTPUT/ميكانيكا/TOL-ADW-DOC-ASB-MECH-001.pdf
OUTPUT/كهرباء/TOL-ADW-DOC-ASB-ELEC-001.pdf
```

## 📊 تنسيق الأرقام التسلسلية

- الأرقام من 1 إلى 999: تُكتب بثلاث خانات (001, 015, 999)
- الأرقام 1000 فأعلى: تُكتب كما هي (1000, 1001, ...)

## 💾 حفظ التقدم

- يتم حفظ آخر رقم تسلسلي لكل تخصص في ملف `counters.json`
- عند إعادة تشغيل البرنامج، يتم اقتراح الرقم التالي تلقائياً
- يتم حفظ سجل كامل بجميع الملفات التي تم إنشاؤها في `history.json`

## ⚠️ ملاحظات هامة

1. **تأكد من تثبيت LibreOffice أو Microsoft Word** قبل تشغيل البرنامج
2. القوالب يجب أن تكون موجودة في مجلد `templates/`
3. البرنامج يدعم إنشاء مئات الملفات دفعة واحدة دون مشاكل
4. في حالة فشل بعض القطع، يستمر البرنامج في معالجة الباقي

## 🔧 تخصيص القوالب

يمكنك تعديل القوالب في مجلد `templates/` باستخدام Microsoft Word أو LibreOffice Writer:

- الحقول المتاحة للدمج:
  - `{{PLOT_NUMBER}}` - رقم القطعة
  - `{{DATE}}` - التاريخ
  - `{{DESCRIPTION}}` - الوصف
  - `{{SERIAL_NUMBER}}` - الرقم التسلسلي
  - `{{DISCIPLINE_SHAPE}}` - اسم التخصص

## 🛠️ استكشاف الأخطاء

### خطأ "لا يوجد LibreOffice أو Microsoft Word"
- تأكد من تثبيت LibreOffice أو Microsoft Word
- على Windows، تأكد من وجود LibreOffice في PATH
- جرب إعادة تشغيل البرنامج بعد التثبيت

### خطأ "القالب غير موجود"
- تأكد من وجود ملفات القوالب في مجلد `templates/`
- تحقق من أسماء الملفات (template_AR.docx, template_CV.docx, إلخ)

### خطأ في Permissions
- تأكد من أن لديك صلاحيات الكتابة في مجلد البرنامج
- شغل البرنامج كمسؤول (Run as Administrator) إذا لزم الأمر
